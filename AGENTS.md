# EDITH project preferences

- The user is a nontechnical 10th-grade student working on a machine learning science fair project.
- Write and maintain the code for the user. Make technical and software design decisions independently within the requested task.
- Explain the work in simple, everyday language. Define necessary technical terms and help the user understand what the code does and why.
- Ask the user about biology decisions, the scientific question, and the intended purpose of the science fair project before making substantive choices in those areas.
- Do not require the user to choose routine coding details. Keep explanations accessible and respectful.
- Do not invent scientific findings or present untested results as established conclusions.

- The user clarified that EDITH is for the Conrad Challenge.
